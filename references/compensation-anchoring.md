# 薪酬锚定

> 目标不是给出一个"值多少钱"的答案，而是给出**可解释的区间、可谈判的结构、以及该在什么时候问什么**。

---

## 一、先把结构拆开

混在一起谈薪酬是寻访中最常见的自伤行为。拿到任何薪酬信息，先拆成五个槽：

| 槽位 | 内容 | 谈判意义 |
|---|---|---|
| 固定 | 月基本 × 12，或年固定现金 | 决定生活质量的底盘，最难谈 |
| 绩效/年终 | 目标值 × 达成率 × 月数 | 波动项，看历史达成率判断实际值 |
| 股权/期权 | 股数 × (最新估值或退出预期) | 未实现的部分要单独标注 |
| 补贴/津贴 | 餐补、交通、住房、子女教育 | 小额但影响实际到手，且通常可谈 |
| 一次性 | 签字费、搬迁、补偿 | 时点性，最容易在 offer 阶段争取 |

**年化口径的常见陷阱**：
- 绩效按"目标上限"算而非"历史实发"→ 虚高
- 股权按最新一轮估值算，但该轮尚未交割 → 虚高
- 把年终月数写满但实际公司从未足额发放 → 虚高
- 忽略补贴与实报实销部分 → 虚低

**正确的算法**：先算"确定到手部分"，再算"条件性部分"，最后算"未实现部分"，三者分列。

## 二、区间锚定

### 维度组合

一个可信的区间，需要锁定五个维度：

| 维度 | 说明 |
|---|---|
| 城市 | 一线 / 新一线 / 二线，同岗跨城差异通常在 20%–40% |
| 职能族 | 同层级的不同职能差异可达 30% 以上 |
| 职级带 | 层级锚（不是职级名） |
| 企业规模类型 | 规模、组织成熟度、融资阶段影响薪酬结构而非绝对值 |
| 数据时点 | 市场在快速变动期，半年前的数据参考价值有限 |

### 数据来源

**优先级排序**：

1. **公开薪酬报告**（有明确方法论与样本说明的）——可引用，需标注来源与时间
2. **公开招聘信息汇总**——量大但口径杂，需筛选同口径样本
3. **顾问自有的历史成交数据**——最贴近实际，但样本量小、时效性依赖维护
4. **人选自述**——只能作为对照，不能作为市场基准

**引用外部数据的三条要求**：
- 写明来源机构/报告名与发布时间
- 写明该数据的适用范围（城市/职能/规模）
- 数据与本判断关系不大时，**不引用**——堆无关数据会稀释报告可信度

### 位置判断

把人选现状与期望放进区间，只做三态描述：

| 位置 | 含义 | 处理方向 |
|---|---|---|
| 区间下缘 | 明显低于同层同职能的市场水平 | 有议价空间，可在推荐时作为动机素材 |
| 区间内 | 处于常规水平 | 涨幅空间取决于职级跨度与结构调整 |
| 区间上缘 | 已在或超过市场中位 | 需靠稀缺性证据支撑；若无，需调整期望或目标岗位族 |

**不做"被低估/合理/虚高"的价值评判**——市场的真实水位比任何人的判断都准。

## 三、三类偏差的判别

同一个"期望 60万"的诉求，可能源于完全不同的原因。判错类型，谈判策略就会错。

### 偏差一 · 结构偏差

**特征**：绝对额看起来正常，但结构失衡。
- 固定部分偏低、浮动部分占比过高 → 年化数字受制于达成率，风险实际更高
- 固定部分偏高、浮动几乎为零 → 现金压力大，职级天花板可能已到

**判别方法**：拆出固定部分单独对标市场固定薪资区间。固定部分偏离明显而总额接近 → 结构偏差。

**谈判含义**：这类人选的真实诉求往往不是"总包数字"，而是"底薪安全感"或"上行空间"。谈的时候把结构摊开谈，比只谈总额有效。

### 偏差二 · 口径偏差

**特征**：比较的双方用的不是同一个口径。
- 人选拿 total package 比岗位广告上的基本工资
- 对方用"年包"含签字费，下一次招聘不含
- 拿股权按最新估值 vs 对方按已实现部分

**判别方法**：问清人选的数字由哪几块构成、分别是什么口径。

**谈判含义**：口径偏差是**最容易解决、也最伤信任**的一类偏差——因为对方觉得自己被"低估"了，而实际上是口径差。处理原则是**先讲结构，再谈数字**，让对方自己看到差异在哪。

### 偏差三 · 周期偏差

**特征**：数字本身没错，但对应的市场时点已经过去。
- 用一年前的薪酬水平做今天的对标
- 在行业收缩期沿用扩张期的基准
- 该职能族当前正处结构性变化中（如某类岗位需求骤增/骤减）

**判别方法**：查该职能族当前市场状态；把数据时点与当前对齐。

**谈判含义**：周期偏差对猎头最有利也最危险——有利在于可以帮人选找到被低估的窗口，危险在于如果拿过期数据去跟客户谈，会在专业性上失分。

## 四、谈薪节奏

### 分阶段原则

| 阶段 | 该做什么 | 该不做什么 |
|---|---|---|
| 首次沟通 | 不问具体数字，只问**结构**（"固定和浮动大概怎么分"） | 不问现薪，不问期望 |
| 意愿确认后 | 可以问区间（用选项而非开放问法） | 不把对方区间原样报给客户 |
| 推荐前 | 内部锁定区间，形成报价区间 | 不在人选面前透露客户预算 |
| offer 沟通 | 逐条对条款 | 不做单一数字的拉锯 |

### 该问清的 vs 不该主动抛出的

**必须在推荐前问清**（否则容易在终局翻车）：
- 现薪的**结构**，不只是总额
- 期望的**驱动因素**（是要数字、要职级、还是要某个具体条件）
- 底线的真实位置（往往不等于期望值）
- 是否有未行权股权、有无竞业
- 期望的**时间窗口**（现在就想动 vs 有计划地看）

**不主动抛出**：
- 你查到的市场区间（会锚定对方的心理预期，反而限制自己的操作空间）
- 客户方的预算区间
- 你的判断（"我觉得你应该要 X"——让对方自己得出这个结论）

### 报价区间的三段式

内部锁价时，准备三个数：

| 段位 | 作用 |
|---|---|
| 起点 | 客户预算的下沿，用于判断这个订单是否值得接 |
| 目标 | 理想成交区间 |
| 上限 | 越过这个数，本单性价比不足，换人可能更划算 |

> "上限"的存在是防止顾问陷入无限拉扯——它把"谈不下来"从个人能力问题变成了商业决策问题。

## 五、薪酬相关的风险提示

| 风险 | 表现 | 提示方式 |
|---|---|---|
| 虚高 | 期望明显超出市场且无稀缺性支撑 | 写明"该区间需要哪些能力证据支撑"，让对方自己判断能否补上 |
| 信息不全 | 不知道股权/浮动结构 | 在信息缺口清单中列明，避免用错误的总额做决策 |
| 口径混用 | 与客户用不同口径比较 | 推荐材料中主动写明采用的计算口径 |
| 时效过期 | 数据周期与当前市场不匹配 | 标注数据时点，必要时注明"近期市场波动中" |
| 敏感信息外泄 | 精确个人薪资出现在交付物中 | 一律区间/分档表述，精确数字不落任何输出 |

## 七、自检

- [ ] 固定/浮动/股权/补贴/一次性是否分开列了？
- [ ] 区间是否标注了城市、职能、职级带、规模类型、时点？
- [ ] 外部数据是否写了来源与时间，且只引用了与判断相关的数据？
- [ ] 偏差类型是否判别了（而非笼统说"偏高/偏低"）？
- [ ] 精确个人薪资是否已从所有输出中移除？
- [ ] "不主动抛出"的部分是否真的没有出现在可交付给客户的材料里？
